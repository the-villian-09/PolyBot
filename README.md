# PolyEdge Lite

PolyEdge Lite v1.2 is a lean MVP Polymarket arbitrage bot focused on clean execution, good filtering, and stability.

## Current scaffold

This repository currently includes:
- TypeScript project setup
- env validation
- structured logging
- core domain types
- orderbook store
- scanner and validation stubs
- Polymarket client stub

## Commands

```bash
npm install
npm run build
npm run dev
npm test
```

## Safety

Default mode should remain `paper` until integration, reconciliation, and execution paths are validated.
